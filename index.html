Make sure your bookmarks bar is visible, then drag the button below onto it:

Auto Place Ads

  1. Grab the blue button and drag it up to the bookmarks bar.
  2. Release. It becomes a clickable bookmark.
  3. When on the ad placing window on YouTube, click the bookmark to run it.

If dragging still won't work, right-click the button, choose "Copy link address," then create a new bookmark manually and paste it into the URL field.
